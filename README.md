# Archives de Havengard

Site statique pour parcourir les planches illustrées du dossier `Bestiaire_RP_Light/images`.

## Contenu

- 46 notices, dont les 45 notices du fichier `bestiaire.html` et une notice issue de la planche de Féraluna.
- Chaque notice possède un résumé distinct, repris des descriptions du bestiaire.
- 50 planches originales copiées dans `public/images/`.
- Les textes détaillés déjà présents dans la version GitHub sont conservés dans les notices concernées.
- Filtres, recherche par nom, surnom, espèce et résumé, et une vue détaillée pour chaque notice.
- Champs séparés : taille, poids, classification, origine, habitat et statut. Les informations viennent de `bestiaire.html` ; une valeur absente reste signalée comme non précisée.
- Chaque notice peut être modifiée depuis sa fenêtre. Les changements sont conservés dans le navigateur ; l’export et l’import JSON servent à sauvegarder ou transférer les modifications.
- Les changements locaux ne sont pas visibles sur le site public avant publication sur GitHub.
- Rayons préparés pour les potions, sortilèges, histoire de la magie et alchimie botanique. Ils sont vides parce que le dossier source transmis ne contient que des planches de bestiaire.

## Aperçu local

Ouvrir `index.html` dans un navigateur. Le site n’utilise pas de compilation ni de dépendances JavaScript.

## Publication

Le dépôt utilise déjà le déploiement GitHub Pages configuré pour sa branche principale. Chaque mise à jour de `main` déclenche la publication automatique.
